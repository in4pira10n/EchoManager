## 简体中文

- SF Symbols 使用 EchoKit 更新后的资源。按钮、导航和设置等组件恢复各自的默认图标尺寸，快捷指令卡片和空状态等独立图标按 SVG 原始尺寸显示。
- 新增快捷指令，可按顺序启动、停止、重启、打开或切换实例。每一步可按实例运行状态选择是否执行。
- 应用文本集中到简体中文资源目录，便于维护和后续翻译。

**升级**。请同时更新 [EchoKit](https://github.com/in4pira10n/EchoKit) 到 `f8d4a3f` 或之后的版本。下载对应系统和架构的压缩包，校验 `SHA256SUMS.txt` 后解压。替换程序时保留现有的配置和数据目录。

## English

- SF Symbols use EchoKit's refreshed assets. Buttons, navigation, and settings follow their component defaults. Standalone symbols, including those on shortcut cards and empty states, use their intrinsic SVG dimensions.
- Add shortcuts that start, stop, restart, open, or toggle instances in sequence. Each step can run conditionally based on instance state.
- Centralize UI text in a Simplified Chinese catalog to make maintenance and future translations easier.

**Upgrading**. Update [EchoKit](https://github.com/in4pira10n/EchoKit) to `f8d4a3f` or later. Download the archive for your OS and architecture, verify it against `SHA256SUMS.txt`, and extract it. Keep your existing configuration and data directory when replacing the executable.
